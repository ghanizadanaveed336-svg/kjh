# Tailor Shop C# Project

This repository contains a WPF C# project that converts the Python tailoring application to a Windows desktop app with a premium dark gold design inspired by the provided tailor branding.

## Features
- Modern WPF UI
- Dark luxury style with gold accents
- Tailor dashboard layout
- Customer, order, payment, and backup sections ready for extension
- Easy to develop further into the full business app logic

## Run the app

### Prerequisites
- Windows 10/11
- .NET 8 SDK

### Commands
```bash
dotnet restore
dotnet build
dotnet run
```

Open the project in Visual Studio 2022 and run it in Debug mode.

## Project structure
- `TailorShop.csproj` - project definition
- `App.xaml` and `App.xaml.cs` - app startup
- `MainWindow.xaml` and `MainWindow.xaml.cs` - main dashboard UI

## Notes
This is a design-first conversion based on the provided application concept and example logo. It is ready for further logic implementation using your existing database and business rules.
